## Style controls

Outline thickness 1-5 px, fill 0-60%, fade start 40-300 m, six color presets, team and visibility separation.

## Presets

| Name | Layers |
| --- | --- |
| quiet | outline only |

Scroll on the preset chip to switch. Presets are stored per profile.

## Install

Extract, admin loader, game, INSERT. Borderless required for the overlay.

## Troubleshooting

Too bright at night: fill 10%. Flicker in clips: streamproof plus game capture. Labels missing: layer toggled off.

Windows 10/11, Steam, EAC.
